##  Overview

ToxiTrend AI is a modern AI-powered moderation dashboard designed to detect toxic comments, analyze harmful discussions, and provide real-time moderation insights using Machine Learning and NLP.

The platform supports:
- Real-time toxicity detection
- CSV bulk analysis
- Reddit-style comment analysis
- YouTube comment analysis
- Toxic trend monitoring
- Secure authentication system

Built with a modern premium UI using Streamlit and Supabase Authentication.
